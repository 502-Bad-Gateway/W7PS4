GITHUB PUBLICATION MODEL

GitHub blocked the authenticated history import because the historical commits contain workflow
files and the Actions token is not allowed to import those files with Git push. W7PS4 is therefore
published as a complete source snapshot produced from the verified local foundation tree. Historical
workflows are deliberately omitted; only the dedicated Graphics Lab plugin workflow is recreated
through GitHub's workflow-authorized API. The exact local history remains preserved in the previously
created history bundle, while this file records the authoritative Build 11 source identities.

IMPORTANT BUILD 11 SOURCE NOTE

The checked-out Git tree is the exact Build 11 branch head, but the Build 11 GitHub Actions workflow
constructed its compiled source by applying these transformations after checkout:

1. ci/build09r2-preserve-fragment-binding-slots.patch
2. ci/build10-disable-push-descriptors.patch
3. ci/apply-build11.ps1
4. ci/fix-build11-draw-sites.ps1

Therefore the unmodified branch working tree is not, by itself, the final source seen by the Build
11 compiler. The integration milestone must materialize those transformations into ordinary source
commits and verify behavioral equivalence before replacing Build 11 policy with plugins.

MATERIALIZATION STATUS

The four transformations are now committed as normal source. Their exact order, historical
identities, modified file set and source-diff fingerprint are recorded in
ci/build11-materialized.json. The resulting Windows 7 binary was physically verified as unchanged
from Build 11 before the discovery-only bridge work began.
